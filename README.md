# 📘 Facebook Clone – Built by Eakshitha Cheppali

This is a fully responsive **Facebook clone** built to replicate the basic structure and UI of the original Facebook platform. The goal of this project was to enhance my front-end development skills by building a real-world clone using modern web technologies.

🔗 **Live Demo:** [Click here](https://thunderous-strudel-721b73.netlify.app/)

---

## ✨ Features

- 🏠 Homepage layout similar to Facebook
- 👤 User profile and sidebar sections
- 📰 News Feed / Posts structure
- 🔍 Search bar (static)
- 💬 Interactive UI elements (like buttons, icons)
- ⚙️ Fully responsive design (desktop and mobile)

> *Note: This is a static front-end clone, and does not include real-time authentication, database, or backend features.*

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3** (Flexbox, Grid, Media Queries)
- **JavaScript** (for interactivity)
- **Font Awesome** for icons
- **Netlify** for deployment
